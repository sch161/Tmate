# 맛궁합 영수증 인쇄 — 맥북에서 처음 시험하는 방법

부스 진행자용 화면(`src/pages/match-print.html`)으로 MXW01 미니 감열 프린터에 사진과 궁합 결과를 뽑는다.
화면 흐름·프로토콜 바이트·SQL 은 자동으로 확인했지만, **실제 프린터와의 블루투스 통신은 실제 기기에서만 확인할 수 있다.** 아래 순서로 한 번 시험한다.

## 준비

- [ ] 맥북의 **Chrome** 을 쓴다 (Safari·Firefox 는 Web Bluetooth 가 없어 안 된다. 화면에 안내가 나온다)
- [ ] 주소는 `https://` 또는 `http://localhost` 여야 한다 (그 외에서는 브라우저가 블루투스·카메라를 막는다)
  - 배포본(이 기능이 main 에 합쳐져 배포된 뒤): `https://t-mate.vercel.app/src/pages/match-print.html?demo=1`
  - 로컬: `npm run dev` 뒤 `http://localhost:5173/src/pages/match-print.html?demo=1`
- [ ] macOS **시스템 설정 → 개인정보 보호 및 보안 → 블루투스** 와 **카메라** 에서 Google Chrome 을 켠다 (처음 쓸 때 묻는 창이 뜨면 허용). 맥북 블루투스가 켜져 있어야 한다
- [ ] 프린터에 용지를 넣고 덮개를 닫은 뒤 전원을 켠다. 충전해 둔다
- [ ] 휴대폰의 프린터 앱이 프린터에 연결되어 있으면 끊는다 (한 번에 한 기기만 연결된다). macOS 블루투스 설정에서 따로 페어링할 필요는 없다
- [ ] T:MATE 에 로그인한다 (진행자 계정)

`?demo=1` 은 서버 대신 예시 팀(데모 데이터)을 쓴다. `supabase/migrations/004_match_print.sql` 을 적용하기 전에는 이 주소로만 팀 목록이 나온다.

## 시험 순서

1. [ ] **프린터 연결**을 누른다 → Chrome 의 기기 선택 창에서 `MXW01`(또는 비슷한 이름)을 고르고 "페어링"
   - 목록이 비어 있으면: 프린터 전원을 확인하고, **"목록에 프린터가 안 보이면: 모든 기기에서 찾기"** 로 다시 연다
   - 성공하면 `연결됨 · (기기 이름)` 과 `프린터가 준비됐어요 (배터리 약 N%)` 가 나온다
2. [ ] **테스트 인쇄**를 누른다 → 종이가 약 3cm 나오고 그 위쪽 2cm 에 무늬가 찍혀야 한다
   - 맨 위 굵은 가로줄이 종이 양 끝까지 찍혔는지
   - 왼쪽 위가 직각인 검은 삼각형의 빗변이 매끈한지 (톱니처럼 끊겨 있으면 알려주세요)
   - 왼쪽이 검고 오른쪽으로 갈수록 밝아지는 띠가 자연스러운지 → 전체가 흐리면 **인쇄 농도**를 "진하게"로, 뭉개지면 "연하게"로 바꾼다
   - 체크무늬와 아래 가로줄까지 찍히고 종이가 조금 더 밀려 나오는지
3. [ ] 방 번호 4자리(데모는 아무 번호)를 넣고 **팀 찾기** → 팀을 고른다
4. [ ] 카메라 허용 → **촬영하기** (3-2-1) → **이 사진으로 미리보기**
5. [ ] 미리보기를 확인하고 **인쇄** → 약 21cm 영수증이 나온다 (보내는 데 20초쯤, 진행률이 보인다)
   - 사진이 너무 어둡거나 밝으면 **사진 밝기**를 바꾸고 다시 인쇄한다
   - 위에 결과 캐릭터, 맨 아래에 사진과 "디지털미식연구반"까지 찍히고 뜯을 여백이 있는지 (길이 약 21cm)
6. [ ] **다음 팀**을 눌러 한 번 더 뽑아 본다. 프린터가 절전으로 꺼졌다 켜진 뒤에는 **다시 연결**을 누른다 (기기 선택 창 없이 붙는다)

## 안 될 때 보내줄 것

1. 화면 왼쪽 아래 **진단 로그**를 펼치고 **로그 복사**를 눌러 붙여넣은 내용 전체 (브라우저 종류, 연결 과정, 보낸 명령, 프린터가 보낸 알림이 시각과 함께 들어 있다)
2. 어느 단계에서 멈췄는지와 화면에 나온 안내 문구
3. 종이가 나왔다면 그 사진 (특히 테스트 인쇄)
4. 프린터 겉면·설명서의 모델 이름

진단 로그 아래의 **"프린터 응답을 기다리지 않고 보내기 (진단용)"** 는 연결은 되는데 `상태 요청에 응답하지 않아요` 에서 멈출 때만 켜 본다. 켜고 테스트 인쇄를 했을 때 종이가 나오는지도 함께 알려주면 원인을 좁힐 수 있다.

## 실제 기기에서 달라질 수 있는 부분

프로토콜은 공개 구현(`src/utils/mxw01-protocol.ts` 상단의 출처)을 따라 직접 작성했고, 출처끼리 다르거나 불확실한 곳은 코드에 "주의" 주석으로 남겼다.

- 프린터가 서비스 UUID 를 광고하지 않으면 기기 선택 창에 안 보인다 → "모든 기기에서 찾기"
- 상태 응답의 오류 코드 해석(용지 없음 등)은 문서 기준이다. 용지가 있는데 오류로 나오거나 그 반대면 로그의 `알림 a1` 줄이 필요하다
- 인쇄 완료 알림이 오지 않는 기기가 있을 수 있다. 종이는 다 나왔는데 `완료 신호를 받지 못했어요` 가 뜨면 인쇄 자체는 정상이다
- 긴 영수증에서 중간에 줄이 빠지거나 밀리면 데이터 전송 간격(지금 15ms)을 늘려야 한다 → 로그와 종이 사진을 보내주세요

## 손님이 폰으로 올린 사진으로 뽑기

1. 손님이 궁합 결과 화면에서 **사진 찍고 영수증 뽑기**를 눌러 둘이 사진을 찍는다 (그 방에서 검사를 마친 두 사람만 올릴 수 있다)
2. 인쇄 화면의 **폰으로 올라온 사진**에 진행자 번호를 한 번 넣는다 (이 탭을 닫기 전까지 기억한다)
3. 목록(5초마다 새로 불러온다)에서 팀을 누르면 그 사진으로 바로 미리보기가 열린다 → **인쇄**
4. 인쇄한 팀은 목록에서 흐리게 "인쇄함"으로 바뀐다. 손님이 사진을 다시 올리면 다시 "대기 중"이 된다

맥북 카메라로 찍는 방식(방 번호로 직접 찾기)도 그대로 쓸 수 있다.
